## DAT 412 Final Project – Hanna Syed
-----------------------------------

Project Title:
Detecting Suspicious Internal Activity Using After-Hours Logon Patterns

Description:
This project uses machine learning to identify whether user logon behavior is suspicious or normal based on after-hours activity. It uses a single feature from the CERT Insider Threat dataset (logon.csv) and applies three classification models.

Included Files:
- FinalScript.ipynb          → Jupyter Notebook with all code
- FInal Scirpt.pdf           → Exported PDF of the notebook
- logon.csv                  → Input dataset
- Project Description.pdf    → Assignment guidelines

How to Run:
1. Open FinalScript.ipynb in Jupyter Notebook or JupyterLab.
2. Run the notebook top to bottom.
3. Make sure you have the following Python packages installed:
   - pandas
   - numpy
   - matplotlib
   - seaborn
   - scikit-learn

Models Used:
- Logistic Regression
- Random Forest Classifier
- Decision Tree Classifier

Outputs:
- Classification reports
- Confusion matrix heatmaps
- 5 EDA plots to explore patterns in the data
